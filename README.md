# Skill Nexis - C++ Week 4

This repository contains the C++ File Handling and STL assignments and mini project completed for Week 4 of the Skill Nexis C++ Programming Internship.

## Week 4 Assignments

### 1. File Write and Read
A program that writes student data into a text file and reads the data back.

### 2. Vector Sorting
A program that uses a vector to store N elements and sorts them in ascending order.

### 3. Student Roll and Name Map
A program that uses a map to store student roll numbers and names.

### 4. Division by Zero Exception
A program that demonstrates exception handling for division by zero using try, throw, and catch.

## Mini Project

### Employee Record Saver

An Employee Record Saver using File Handling and STL.

Features:
- Employee records stored using a vector
- Employee data written to a text file
- Employee records read back from the file
- File handling using `ofstream` and `ifstream`

## Concepts Used

- File Streams
- `ofstream`
- `ifstream`
- Vectors
- Maps
- STL
- Exception Handling
- `try`
- `throw`
- `catch`

## Project Files

- `file_read_write.cpp` — File write and read
- `vector_sort.cpp` — Vector sorting
- `student_map.cpp` — Student roll and name map
- `division_exception.cpp` — Division by zero exception handling
- `employee_record.cpp` — Employee Record Saver mini project
- `student.txt` — Student file-handling output
- `employees.txt` — Employee records saved by the mini project
